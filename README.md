# Dynamic Path Tracing For Cutscenes

A Witcher 3 Next-Gen mod that automatically enables Path Tracing or Ray Tracing during cutscenes and dialogues, seamlessly restoring your normal gameplay graphics when the scene ends.

---

## Features

- **Dynamic PT/RT Switching:** Automatically engages Path Tracing or Ray Tracing during cinematic scenes and dialogues.
- **Debounce Protection:** Smooth transitions that prevent rapid graphics switching when skipping dialogue lines.
- **Scene Customization:** Configure separate lighting profiles for story cutscenes and conversational dialogues.
- **In-Game Menu:** Full configuration under Options > Gameplay > Cutscene Path Tracing.
- **18 Languages:** Fully translated into all official game languages.
- **No Script Conflicts:** Built with modern REDengine annotations without editing vanilla script files.

---

## Installation

Extract the release zip into your Witcher 3 root directory:
```
The Witcher 3/
├── bin/
└── mods/modCutscenePT/
```
Or install via your preferred mod manager (Vortex, MO2).

---

## Compatibility

- The Witcher 3 Next-Gen (v5.00+) DX12.
- Fully compatible alongside Dynamic Region Graphics.
